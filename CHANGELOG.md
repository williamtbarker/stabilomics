# Changelog

All notable changes follow the spirit of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-09-03

### Added

- Linear-programming LAD-LASSO with unpenalized numeric covariates.
- Seeded repeated-subsampling stability selection.
- CSV, TSV, and content-detected gzip input.
- Deterministic JSON, CSV, and Markdown reports.
- Optional stable-feature-count and median-Jaccard workflow gates.
- Deterministic heavy-tailed synthetic fixture generator.
- Unit, integration, packaging, linting, typing, and CI configuration.

### Fixed

- Generated CSV files use portable LF line endings, keeping Git whitespace checks clean on macOS and Linux.
